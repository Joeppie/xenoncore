xenoncore

The XenonCode language core for the game Archean: project model, analyzer, function-reference docs, program sites, and the craft decompose/pack codec — pure TypeScript, no app. It feeds the blueprint editor, a VS Code extension, and AI tooling (plan § P10).

  • ▶ Playground — boot the real XenonCode wasm in the browser: load a bench craft's disk, edit the program, run it, watch the screens (the zero-dependency POC; bench fixtures under /testdata/).
